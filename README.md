# Phrase Trainer

Минималистичный веб-тренажёр для изучения английских фраз.  
Создан для личного использования — без геймификации, без отвлекающих элементов, только практика.

[🚀 Open App](https://mariannamari.github.io/phrase-trainer/)
---

## ✨ Возможности

### 📚 Sections (разделы)
- Разделение фраз по темам
- Быстрое переключение между модулями

---

### 🟢 Tutorial (просмотр)
- Все фразы отображаются списком
- Для каждой фразы:
  - phrase
  - definition
  - translation (можно скрыть/показать)
  - example
- Озвучка:
  - phrase
  - example

👉 Идеально для быстрого повторения перед уроком

---

### 🟡 Flashcards (карточки)
- Показывается только definition
- Нужно вспомнить phrase
- После ответа:
  - показывается phrase, example, translation
- Самооценка:
  - Не знал
  - Почти
  - Знал

Простая логика повторения:
- Не знал → скоро повтор
- Почти → позже
- Знал → в конец очереди

---

### 🔴 Fill in the blank
- Пример с пропуском:

  `She learned to code _____ with no previous experience`

- Ввод ответа
- Проверка без учёта регистра
- После ответа:
  - правильная фраза
  - перевод
  - объяснение

---

## 🔊 Озвучка

Используется **SpeechSynthesis API (браузер)**  
Работает без сторонних сервисов.

Сохраняется:

- последний режим
- прогресс flashcards

## 🚀 Запуск проекта

Установить зависимости:

```bash
npm install
```

Запустить dev-сервер:

```bash
npm run dev
```

Собрать production-версию:

```bash
npm run build
```

Предпросмотр сборки:

```bash
npm run preview
```

## 🌐 Деплой (GitHub Pages)
